# 리테일 도메인 최종 프로젝트 frontend

LG CNS AM Inspire Camp 6기 최종 프로젝트 4조의 프론트엔드 레포입니다. 백엔드는 [backend](https://github.com/LGCNS-AM06-Final-TEAM4/backend) 레포에 있습니다.

주제는 아직 정하는 중입니다. 팀이 확정하면 이 문서에 화면 구성과 실행 방법을 채웁니다.

## 기술 스택

수업에서 직접 다룬 스택을 기준으로 정했습니다. 주제 확정 후 조정할 수 있습니다.

| 영역 | 기술 |
| --- | --- |
| 화면 | React, Vite |
| 라우팅 | React Router |
| 통신 | axios (API 주소는 `.env`로 관리) |

프로젝트 생성은 주제와 화면 흐름이 정해진 뒤 진행합니다.

## 협업 규칙
